## Troubleshooting Common Issues

Install issues? Install the audio interface driver first, then select it in preferences and set a workable buffer size.  
Performance problems? Freeze heavy tracks, increase the buffer, and move sample libraries to an SSD.  
License/activation? Authorize with the Ableton account that owns the licence and refresh offline authorization if needed.  
Compatibility? Update when a plugin fails validation after an operating system update.  
Update failures? Quit the app before updating and reinstall if the library database becomes corrupt.
